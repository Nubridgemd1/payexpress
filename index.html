For IMTOs, banks & fintechs in Nigeria

Plug PayExpress into your payout rails

PayExpress collects the sender's USD in a US receivable account, screens it, and pushes the payment instruction to your platform in real time. You credit the beneficiary once the corresponding USD has settled in that receivable account - so every payout is backed by funds you can see, with no pre-funding risk. Connect with a single REST API and webhook.

One REST API

Create payouts, check status, and reconcile with a documented JSON API and sandbox keys.

Webhooks

Real-time delivery, failure, and settlement events pushed to your endpoint.

Compliance at source

US-side KYC/AML/OFAC done before funds reach you - traceable, pre-screened flows.

FX & settlement

Agreed rate and margin per transfer; USD settlement to your nostro on a set cycle.

Any payout method

Bank (NUBAN), card, mobile wallet, or cash - route to whatever you support.

CBN-aligned

Built to operate within the CBN IMTO / authorised-dealer framework.

Instructions arrive in real time, each carrying a settlement confirmation. Your platform credits the beneficiary only once the matching USD has settled in the US receivable account - no pre-funding, no payout risk.

The real-time instruction your platform receives

// Webhook (real time) -> POST https://your-imto.ng/webhooks/payexpress
{
  "event": "payout.instruction",
  "reference": "PX-8842013",
  "settlement_status": "settled", // USD confirmed in US receivable a/c
  "usd_amount": 500.00,
  "amount_ngn": 792500,
  "method": "bank_account",
  "recipient": { "name": "Test Recipient One", "bank_code": "058", "nuban": "0123454471" }
}
// You credit the beneficiary, then acknowledge:
